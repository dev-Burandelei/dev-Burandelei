## 🚀 Projetos em destaque

### 🤖 RAG_POST — Retrieval-Augmented Generation
**Python | LangChain | ChromaDB | Embeddings | LLMs**

Projeto de implementação de uma arquitetura RAG para consultar documentos PDF utilizando recuperação semântica e modelos de linguagem.

- Extração e processamento de documentos.
- Divisão de documentos em chunks.
- Geração e armazenamento de embeddings.
- Recuperação contextual com ChromaDB.
- Integração com modelos de linguagem.
- Interface para interação com a base documental.

[🔗 Ver repositório](https://github.com/dev-Burandelei/RAG_POST)

### 🎥 Video Frame Interpolation with Generative AI
**Python | PyTorch | Deep Learning | Diffusion Models**

Projeto de iniciação científica voltado à interpolação de quadros de vídeo utilizando modelos generativos de difusão.

- Implementação e experimentação com modelos de Deep Learning.
- Estudo e aplicação de Brownian Bridge Diffusion Models (BBDM).
- Treinamento e avaliação com bases de dados de vídeos.
- Avaliação de qualidade utilizando LPIPS.

**Resultado experimental:** LPIPS médio de 0,0309.
